# TeleBox Player

Android app to browse a TeleBox / LinkBox share link and stream its videos.

- Folder browsing with thumbnails, durations and sizes
- Search inside a folder, breadcrumbs, Android back button
- Built-in player (MP4 + HLS) with Prev/Next and autoplay
- "Open in VLC" and "Copy link"
- Share a link from any app → "TeleBox Player" to open it directly

The APK is built by GitHub Actions on every push to `main`; download it from the repo's **Releases** page.
